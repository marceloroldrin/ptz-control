PTZ Control

Controle câmeras PTZ pelo navegador, app desktop ou Custom Browser Dock do OBS. Sem instalar Node.js no Windows.

Como usar

  1. Baixe e abra o instalador (ou o portable).
  2. Configure o IP da câmera em ⚙ (UDP 52381 ou TCP 5678).
  3. No OBS: Docks → Custom Browser Docks → http://127.0.0.1:8765
